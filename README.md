# US Expat Tax Services — Next.js demo site

Marketing site built from the requirements spec: Home, About, 6 Divisions, 28 Services, 29 Forms, 16 Countries, Contact (+ Book / Quote), Pricing, FAQs, Blog/Resources, Deadlines Calendar and legal pages. All pages are statically generated (SSG), so search engines get full HTML.

## Run it

```bash
npm install
cp .env.example .env.local   # fill in what you have
npm run dev                  # http://localhost:3000
npm run build && npm start   # production
```

Deploys as-is to Vercel (or any Node host). Requires Node 20+.

## Environment variables

| Variable | Purpose |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | Canonical URLs, sitemap.xml, schema |
| `NEXT_PUBLIC_CLIENT_PORTAL_URL` | External Client Portal link (no SSO) |
| `NEXT_PUBLIC_BOOKING_EMBED_URL` | Optional Calendly-style embed on Book a Consultation; the native form is always shown too |
| `NEXT_PUBLIC_GA_ID` | GA4 ID, loads only after analytics consent (Consent Mode v2) |
| `LEAD_WEBHOOK_URL` | Where form leads are POSTed as JSON (CRM / Zapier / Make). Unset = logged to server console |

## Where things live

```
src/data/            ← all content (CMS-ready content model)
  site.ts            firm name, contact, credentials (placeholders)
  types.ts           content model for every templated page type
  divisions.ts       6 divisions
  services.ts        7 themes, 28 services
  forms.ts           6 themes, 29 forms
  countries.ts       16 countries
  content.ts         FAQs, deadlines, pricing, blog posts
src/app/             ← routes (App Router), one template per page type
src/components/      ← Header (mega-menu), Footer, Breadcrumbs, LeadForm, filters, cookie banner
src/app/api/lead/    ← lead intake: validation, honeypot, rate limit, webhook
```

**Adding a page = adding an entry** to the right data file. Service ↔ Form ↔ Division ↔ Country links are drawn from the slugs in each entry, so cross-links appear automatically. To move content into a headless CMS (Sanity, Contentful, Payload), keep the shapes in `types.ts` and swap each `getX()` helper for a CMS query.

## Built-in features (mapped to the spec)

- **Navigation:** themed dropdowns for Services and Forms, a mobile menu, breadcrumbs with BreadcrumbList schema, and a footer with a condensed sitemap
- **Lead capture:** Book a Consultation (time zone auto-detected, preferred date and time) and Request a Quote (situation, country, urgency). Both have required-field validation, a consent checkbox, an optional marketing opt-in, a honeypot and a rate limit. Each has its own noindex thank-you page, so conversions can be counted
- **Analytics:** GA4 events `cta_click`, `generate_lead` and `consultation_booked`, sent only after cookie consent
- **SEO:** unique title, meta description and canonical tag on every page. Form titles follow `[Form Number] ([Form Name]) | [Firm]`. Country pages target "US taxes in [country]". Schema: Organization/AccountingService, Service, FAQPage, BreadcrumbList and Article. `sitemap.xml` and `robots.txt` are generated automatically, and URLs end with a trailing slash (`/forms/5471/`)
- **Search and filters:** Forms hub search by form number; FAQs by keyword and category; Deadlines by country and situation, with add-to-calendar (.ics); blog posts by tag
- **Compliance:** cookie banner with Consent Mode v2, footer disclaimer, sample Privacy/Terms/Cookies/Accessibility pages, a "last reviewed" note on Form, Service and Country pages, and an author/reviewer byline on blog posts
- **Security:** security headers set in `next.config.ts` (HSTS, nosniff, frame options, referrer policy)
- **Accessibility:** skip link, labelled fields, `aria-invalid` on form errors, visible focus, Escape closes menus, reduced-motion support

## Visual layer

- **Illustrations:** these are hand-built SVGs, so there are no stock photos and nothing to license. There's an animated globe with flight arcs on the home page, plus a section illustration in each page header: documents for Forms, a globe for Countries, a shield for Services, a calendar for Deadlines, and so on. Icons for divisions and service themes are in `src/components/Icons.tsx`. A branded social-share image is generated by `app/opengraph-image.tsx`
- **Glassmorphism:** frosted-glass surfaces come from three classes: `.glass` on dark backgrounds, `.glass-light` on light ones and `.glass-dark` on tinted ones. They're used for the header once you scroll, the hero situations panel, the floating chips, the stats, the "How it works" cards, testimonials, the CTA band, the side CTA box, the dropdowns and the cookie banner. Browsers without `backdrop-filter` get solid colours instead
- **Motion:** there's a staggered load-in on page headers, and sections and cards fade up as you scroll (`.reveal`, `.reveal-stagger`). Stats count up from zero, hero chips and background blobs float, the globe arcs and city pulses animate, cards get a hover sheen, and the main button has a shine sweep. All motion switches off for visitors who've turned on "reduce motion" in their system settings

### Scroll text & card transitions

- **Word-by-word headings:** `<SplitText text="…" />` in `src/components/SplitText.tsx`. It's used for page titles, section headings, FAQ headings and CTA titles, and a short underline draws in under section headings.
- **Automatic text reveals:** any plain `h2`, paragraph, list item, table or callout in the page body fades and rises in as it scrolls into view. The selector list is `AUTO_TEXT` in `Motion.tsx`.
- **Card transitions:** cards tilt in 3D toward the mouse, with a spotlight that follows the cursor. They also lift on hover, shrink slightly when clicked and come in one after another with a blur. This covers service, division, country, blog, pricing, process, stat, testimonial and side-CTA cards (`CardFx` in `Motion.tsx`). Touch screens skip the tilt.
- **Page transitions** (`app/template.tsx`) and a **scroll-progress bar** across the top.
